## 行为约束

真实数据缺失时显示不可用或具体错误，生产界面不使用设计稿的示例读数。
普通设置完成输入后自动提交并回读；确实需要中断连接的修改先显示影响。
取消和失败保留原值；超时不能视为写入失败后自动重复请求。
长配置完成编辑后执行一次校验、保存和重载。

状态更新保留编辑草稿、阅读位置与当前选择。页面隐藏或退出会话后停止订阅。
各服务独立运行，保留已有远端路由、管理连接与部署恢复机制。
原生材质采用弱透明、细边缘与缓存的静态层次，不增加持续模糊与常驻动画。

旧界面的未提交改动暂时保留在原文件中，不并入本次实现提交。
