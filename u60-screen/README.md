# U60 Pro Dash 机身屏幕

本目录包含 **Rust + Slint 原生屏幕程序**和浏览器交互原型。原生程序已在 U60 Pro/B31 上跑通显示、触摸和限时退出恢复，机身模式通过认证后的 agent 接入基础实时状态与 Tailscale 状态，并支持可配置的路由/TCP 检测。13 个分类、79 个原生入口复用浏览器的功能设计，未接入的业务页会明确提示。桌面默认使用演示数据。

```bash
bash u60-screen/native.sh preview       # 电脑上的原生窗口
bash u60-screen/native.sh build-device  # ARM 静态构建
bash u60-screen/native.sh trial 120     # ADB 限时试运行，自动恢复原厂界面
```

**[原生开发、设备试运行与当前边界 → NATIVE.md](NATIVE.md)**

下面介绍浏览器原型：基于本仓库的 `zte-agent` 功能设计，提供 320×480 机身屏幕的完整交互模型。一级导航是「概览 / 网络 / 应用 / 设备」，13 个分类下共 76 个浏览器功能入口，每项功能通过小屏列表、独立详情、表单、操作确认和结果页组织。

## 打开预览

直接用浏览器打开 [`preview/index.html`](preview/index.html)，无需安装 npm 依赖，也不需要联网。

也可以在 Linux 电脑运行：

```bash
# 在仓库根目录运行
bash u60-screen/preview.sh
```

然后访问 <http://127.0.0.1:8765>。如果端口占用，可设置 `U60_PREVIEW_PORT=8766`。脚本只在电脑的 `127.0.0.1` 启动静态文件服务。

## 已有交互

- 概览：蜂窝状态、信号详情、流量曲线、热点客户端数量、Tailscale 网络入口。
- 网络：双频 Wi-Fi、访客网络、客户端详情、LAN/DHCP、数据与漫游、制式、运营商、APN、套餐、恢复策略、载波、锁频/锁小区、邻区、STC、信号检测、WAN、NAT、防火墙、DMZ、UPnP、端口转发、QoS、VPN/ALG、TTL、域名过滤、DNS/DoH/缓存。
- 应用：Tailscale 登录引导/服务/配置/版本、短信阅读/发送/回复/删除/转发、SIM PIN/PUK、eSIM 配置/下载/回执、通话/USSD/STK、测速、AT、进程、流量、连接记录、计划任务、iPhone 实时活动。
- 设备：电池详情、充电控制、省电、快速启动、休眠、USB、设备信息、屏幕偏好、HTTPS、后台连接、重启/恢复出厂流程、备份恢复指引。
- 模拟表单保存、项目新增/修改/删除、密码与地址输入校验、多选频段、短信收发、eSIM 下载与测速进度、取消和操作确认。已启用的 eSIM 配置不能直接删除。
- 演示场景：正常、子网路由节点离线、蜂窝断开、低电量。Tailscale 在线与远端子网可达分开显示。
- 中性白灰 / 深灰主题，6 种强调色预设、取色器和 HEX 输入。明暗与配色分别调整，立即生效并在当前浏览器保存；正常、警告、错误使用独立状态色。
- 亮度、亮灭屏、左右滑动和方向键切页。空格模拟电源键；输入框内不抢占键盘操作。
- 电脑侧可以搜索全部功能并直接跳转；例如 `index.html#nr-bands` 可以直接打开频段页。

所有读数都是虚构演示数据，业务操作只改变当前浏览器内存，刷新页面或「还原演示」会还原这些演示数据。主题明暗与强调色单独保存在浏览器的 `localStorage` 中，刷新和「还原演示」会保留；不会持久化表单、密码或演示业务数据。原型没有 HTTP API 客户端、ADB、SSH 或设备写入通道，不会发送短信、改变网络或控制真实设备。

## 调整配色

电脑侧「04 调整预览」可以切换深浅模式，再选一枚预设色，或用取色器 / HEX 输入自选颜色（支持 `#F80` 与 `#FF8800`）。小屏「设备 → 全部设备设置 → 系统设置 → 屏幕与外观」也能修改明暗和强调色，点击「保存屏幕偏好」应用。两处控制保持同步。

背景、正文与分隔线使用中性色；强调色用于数字、选中项、图标和主要按钮。按钮保留所选颜色，按钮文字自动选择黑或白，强调文字根据明暗主题调整亮度。极亮或极暗的自选色不会让文字与背景融为一体。告警仍显示橙色，故障仍显示红色。

「恢复默认蓝色」只重置强调色，保留深浅选择。浏览器禁止本地存储时仍可换色，但页面会提示无法记住此次修改。偏好按浏览器及页面来源保存，直接打开文件与通过 `127.0.0.1:8765` 访问是各自独立的。

## 与现有工程的关系

当前版本只增加本目录，保留原有 `zte-agent`、网页后台及已配置的 Tailscale 网关。源码参考基线是 `03f86da` 加本地网关改动；具体文件包括 `zte-agent/src/server.rs`、`src/tailscale/mod.rs`、`src/sms_forward.rs`、`ui/navigation.js`、`ui/controls.js` 和 `docs/events.md`。

功能清单已关联到本版本 `server.rs` 中的 198 个生产 HTTP 路由。这里的覆盖指「界面入口和交互模型有对应关系」，不表示已经实现或实测了 198 个设备接口。部分页面包含多项 API 操作；例如一个 eSIM 页面包含读取、切换、重命名和删除。

备份/恢复目前没有 agent API，因此小屏只提供配套端操作指引。局域网吞吐测试需要热点客户端参与；iPhone 实时活动需要在手机 App 注册；Tailscale 网页授权需要手机/电脑完成。这些边界在相应页面有说明。

## 浏览器原型与原生程序

`preview/` 是浏览器 HTML/CSS/JavaScript，不能直接作为 litehtml 页面推到设备上。实体版本使用独立 Rust/Slint 页面，已完成第一阶段 DRM 与触摸验证，见 [NATIVE.md](NATIVE.md)。以下仍是业务接口接入时的设计约束。

`u60-screen` 作为独立进程，业务数据路径为：

```text
zte-agent 的认证 API / SSE
          ↓ 数据适配、字段校验、连接和过期状态
独立屏幕进程：页面状态 + 渲染 + 触摸 + 电源键
          ↓
DRM/KMS → 机身屏幕
```

保留当前 agent 作为网络与 Tailscale 的管理者。屏幕通过现有接口读取状态、提交操作，屏幕异常不应导致 agent 或 Tailscale 退出。

- 基本状态复用 `/api/events`，Tailscale 状态复用 `/api/tailscale/status`；设备端独立检测实际路由与目标 TCP 端口，不能仅凭 Tailscale 在线显示「目标可达」。
- 本机 HTTP 使用现有认证，支持令牌过期重登及离线状态；不会给 `127.0.0.1` 增加免认证入口。
- 已有触屏 ASCII 键盘；中文输入法、完整 CJK 字库、长文本编辑和长时间功耗仍需适配。浏览器输入控件与设备能力分开验证。
- 熄屏关闭实时订阅，遵守 agent 无订阅不采样的设计。
- 原厂屏幕进程参与固件启动同步；必须保留早期启动，在系统完成同步后才接管显示。验证阶段先手动启动并安排独立回退，再考虑自启。详见仓库 `CLAUDE.md`。

## 本次验证

通过本地无头 Chrome 检查全部 76 个入口，确认 320×480 逻辑尺寸、无脚本异常及功能页面无横向溢出。另检查表单保存、非法 IPv4、列表增删、短信、eSIM 下载与保护、测速进度、目标离线、会话过期、主题和电源交互，以及 320/390/768/1366 宽度的预览容器。测试不访问真实路由器。

配色更新另外检查预设与自选色、HEX 连续输入和校验、刷新记忆、两处设置同步、切换时保留表单草稿、离线本地设置、损坏或不可用的浏览器存储，以及极亮 / 极暗颜色下的文字对比度。
