# 原生屏幕刷新策略

本轮按全部 82 个设计入口盘点。首页、锁屏继续订阅信号、电量和速率；导航、外观及设置页不加周期刷新。这里的「读取」不等于重绘：读数未变化时，不更新界面模型或像素；变化时只通知对应行，由软件渲染器提交变化区域。新增、删除条目或文本高度改变时，相关布局会随内容调整。

## 共用行为

- 后台读取保留当前页面，不显示占位页或反复切换「正在读取」。多接口结果齐备后统一更新，避免半页新数据、半页旧数据。后台读取不阻挡点击；进入详情、编辑或确认时取消未完成的背景批次，忽略迟到响应。
- 列表按稳定记录标识更新，保留滚动位置；停在列表中部时，新记录插入或前面的记录删除后尽量保持同一条记录在相同位置。删除当前记录时使用其后仍存在的记录；返回其他页面仍按正常导航定位。
- 短信列表每 10 秒检查；短信正文、回复和撰写期间不轮询。表单编辑、未保存草稿、确认窗口期间暂停背景更新。超过 60 秒的写入前读取仍保留草稿，要求再次核对后确认。
- 已有 SSE 订阅的新鲜数据直接更新数值，跳过重复 HTTP 查询；若该主题失效，混合读取页面恢复对应 HTTP 读取。二维码内容不变时复用原图，不重新编码。
- 扫描、测速、下载、更新等任务仅在进行时每 3 秒读取；操作刚被接受后保留最多 15 秒的短暂观察，兼容固件延迟报告状态。邻区扫描没有可靠完成标记，操作后最多观察 30 秒，不持续轮询、不自动重发操作。
- 锁屏、熄屏、离开页面停止该页后台读取。状态无效仍显示错误；移除通用按钮的页面在读取失败时重新提供「刷新状态」，避免没有重试入口。

## 保留的手动操作

正常状态仅 DNS 缓存、短信存储、eSIM 配置清单、eSIM 回执四页保留通用「刷新状态」。这些是按需查看的快照或可能被外部设备改变的清单，不必持续轮询。

「重新扫描邻区」「开始信号检测」「检查发行版本」等有明确含义的业务操作保留；Tailscale 连通性检测保留主动检测，后台连接保留重新连接。eSIM 页面在卡片不可管理时停止自动读取，保留重试。SIM 工具菜单只在进入、操作后或报告忙碌时读取，不把会话状态事件当成菜单响应。

## 验证

63 项原生屏幕回归与严格 Clippy 检查通过；目录覆盖与五种语言资源检查通过。

控制器回归覆盖完整批次提交、相同数据不增加页面版本、后台读取不禁用交互、取消迟到响应、短信阅读／回复暂停、过期草稿恢复、SSE 与轮询互补、任务结束停止轮询，以及写入前核对和失败不重发。

使用与机身相同的 RGB565 持久缓冲区验证：相同短信批次没有像素损伤；单条短信或单个信号值改变只更新局部区域；新短信插入保留阅读锚点；相同二维码内容复用图像。演示数据不包含真实短信、热点凭据或网络配置。

本次合成场景中，相同短信批次重绘 0 像素，单条短信变化重绘 10,094 像素，单个信号值变化重绘 11,424 像素；整屏为 153,600 像素。这些是渲染器报告的更新区域，实际范围随文本和布局变化。首页 Wi-Fi 另验证相同读数续期及密码变化替换二维码，避免把「没有重绘」误当成「没有新读取」。
