日期：2026-11-03。设备：ZTE U60 Pro / MU5250，固件 B31。当前业务数据为演示数据；本记录不代表 agent 业务接口已接入。

拆分提交时，未接入锁屏的基础界面也独立编译并通过 4 项 Rust 测试，再加入锁屏提交，最终版本重新通过上述 8 项 Rust 测试。

## 实机结果

- DRM 显示模式为 320×480，RGB565，pitch 640；已完成首帧 `DIRTYFB` 提交。
- Sitronix 触摸按设备名称与能力识别；显示和触摸分别旋转 180°，用户确认方向与点击位置正常。
- 用户确认状态锁屏、长按解锁正常，小字比初版清楚。
- 随后将长按门槛从 1.5 秒调整为 1 秒，重新通过测试并完成 60 秒实机试运行；这次时长调整尚未得到单独的手感反馈。
- 多次限时试运行结束后恢复原厂界面；最后一轮日志确认 `trial ended normally`、`vendor UI running; backlight restored`，随后只读检查确认原厂 UI 进程存在且无活动试运行。
- 日志记录过熄屏和唤醒，但物理电源键在各场景下的行为、充电模式和长时间功耗仍需验证。可选密码已通过自动化键盘与存储测试，尚未取得用户在实机上设置密码的单独确认。
