# 原生功能接入记录

本文件区分真实功能、自动验证和实机验证。浏览器原型仍使用模拟数据；原生机身模式通过认证后的 agent 工作。

当前 82 个入口的自动更新与手动刷新规则见 [页面刷新盘点](docs/refresh-policy.md)：后台读取保留内容，只更新有变化的行；短信阅读和输入不受周期轮询打断。

字库已从固定界面子集扩展为完整 Noto Sans SC，保留真实可变字重，以支持动态中文设备名称和短信。列表刷新在编辑或确认期间暂停；SSE 的高频更新不会推迟其他数据的定时读取。

真实写入需要在屏幕确认。设置表单优先只提交修改过的字段，固件要求完整对象时先校验整组参数；读取失败的设置不能写入。状态过期时重新读取并保留草稿，用户需再次核对后保存。一次确认只使用一次；写入超时或失败不会自动重发，多个请求中任一失败会停止后续请求。锁屏/熄屏取消尚未发出的请求并清空草稿；已送到后台的请求无法靠关闭屏幕撤回。

设备验证仅执行读取。热点重载、蜂窝切换、充电控制等实际写入结果需要单独验收，不能把字段读取通过等同于硬件动作已验证。

全部 82 个设计入口均已有实现：78 个通过功能控制器组织接口或配套指引，另 4 个为外观、锁屏、后台登录和 Tailscale 连通性本地流程。此覆盖不代表所有设备固件支持全部后台方法，也不代表所有真实写入已实机验收。完整设计入口见 [FEATURES.md](FEATURES.md)。

按 HTTP 方法与路径去重，当前后台 218 个接口中，原生直接接入 199 个（91.3%）。剩余 19 个接口的替代调用或配套端边界见 [API-COVERAGE.md](API-COVERAGE.md)；页面入口数量不能代替接口覆盖率。

## 路由与列表阶段

新增 LAN/DHCP、蜂窝数据/漫游/飞行模式、首选网络、流量套餐、防火墙、NAT、DMZ、UPnP、QoS、VPN 穿透、DNS/DoH/DoT 与缓存；APN 支持新增、修改、启用和删除，端口与域名规则支持新增、删除和总开关，运营商支持扫描、注册和自动选择。

- LAN 校验子网、网关、地址池范围、租期，向固件分别提供完整地址与 DHCP 偏移。
- DMZ/端口目标必须属于当前 LAN，拒绝广播、网络和网关地址；拒绝与已有端口规则冲突。
- DNS 使用后台的统一检测与恢复事务。测试草稿不会保存 DNS，测试后保留草稿。
- 删除、APN 更改及 LAN 相关操作在真正写入前再次读取核对；失败或列表变化取消全部未发送的写入。端口删除同时携带后台支持的原始规则列表校验。
- 输入器支持多行文字；真实中文内容使用完整字库。触屏键盘当前提供 ASCII 字符，可用电脑预览的系统输入法输入中文。
- 一次确认仍只执行一次。失败后主动读取状态，保留失败提示；不会重发原写入。

状态详情阶段的 B31 只读核对已完成：信号、载波、客户端、WAN、系统、进程、电池、SIM 与短信容量均可读取。设备当前安装的后台没有 WireGuard API，该页显示不支持并禁用启停；仓库实现保留，需后续部署兼容后台。

## 短信、SIM 与射频阶段

新增短信读取、回复、发送、阅读标记与删除；SIM PIN/PUK 验证、PIN 开关与修改、网络锁解锁；NR/LTE 频段偏好、小区锁定、邻区扫描、STC、信号检测、互联网测速与 AT 终端。

- 短信使用固件所需的 UTF-16 编码，支持中文及代理对；真实中文内容以独立正文区显示。
- SIM 操作在剩余尝试次数未知或为零时禁用；最后一次额外输入 LAST。提交前重新读取身份和次数，失败后清空输入，不自动重试。读取仍受已安装后台的 SIM 缓存策略约束。
- 频段偏好与当前工作频段分别展示，不能读取当前偏好时不虚构配置。开始扫描、测速、AT 等均需确认；AT 返回内容可本地清空。
- 确认页展示包括默认值在内的目标参数，敏感字段只显示「已填写」；全部读取失败时禁用该页写入。

验证覆盖消息编解码、固件返回失败、SIM 次数与身份核对、频段及小区请求体；写入仅验证请求契约，尚未在设备执行收费或网络切换操作。

## 服务与卡片管理阶段

新增 Tailscale 手机授权二维码、认证密钥登录、服务启停、退出与指定版本安装；USB 模式与反向供电；HTTPS 启用、更新证书和重置；后台发行检查、下载、安装与回退；通话、USSD、SIM 工具菜单；eSIM 配置、预览下载与回执；独立 WireGuard 配置导入和启停。

- Tailscale 指定版本默认 1.104.4，安装需填写官方 ARM64 tgz 的 SHA-256。二维码用整数像素生成，不缩放模块。
- eSIM 下载先预览，再确认套餐；确认/取消携带后台实例与下载开始时间，配置变更前核对芯片与列表。启用中的配置不能删除。
- 后台更新按真实签名与恢复能力启用按钮，恢复出厂、重启和 HTTPS 重置需额外输入确认文字。
- 需要手机信任证书、建立实时活动或另一端测速的流程继续由配套设备完成。

B31 只读核对中，Tailscale、USB、HTTPS、通话状态与实时活动可读取；设备当前后台没有 WireGuard 和在线更新接口，对应写入禁用。eSIM/STK 会建立卡片会话或恢复回执处理，本轮无人值守读取主动跳过。服务切换、通话与套餐操作尚未实机执行。

## 自动化与完整接入验证

- 自动转发支持 Telegram、Webhook、短信、ntfy、Discord 和 Slack：创建、编辑、启停、删除、按发送方/内容筛选、明确确认的测试发送；已有凭据留空保留，不回显。失败重试绑定短信、规则和时间标识，并核对当前规则版本。
- 计划任务支持单次日期、每周重复、五种常用操作、后续重新启用及自定义后台请求；可编辑、启停和删除。时间按设备本地时区解释，拒绝无效日期、过去的单次时间和递归计划任务。
- 条件表单只显示与当前选择相关的字段，保留未保存草稿；点击始终使用原始字段索引，隐藏字段不会导致编辑错项。确认页包含目标默认值并隐藏凭据正文。
- 连接记录仅记录本次屏幕程序观察到的后台连接、蜂窝制式变化，最多 100 条，不持久化；熄屏时不持续订阅。首页数量来自真实连接列表，地址提示记录不作为在线设备计数。
- B31 的 `pin_status=5` 保持未知，修改保护状态必须明确选择开启或关闭；不把它默认为关闭。提交前核对后台实例、SIM 身份、状态与次数。
- 缺失的 ubus 方法直接显示不支持，不再按后台繁忙自动重试。读数不完整的字段保持不可用。

### 普通 SIM 的 eSIM 提示修正

后续按用户反馈读取 `/api/esim/chip` 与 `/api/esim/profiles`：后台均返回 HTTP 502，错误为 `QMI error 80 SimFileNotFound`，配置列表还返回 `kind=management_unavailable`。用户确认插入的是普通运营商 SIM；U60 Pro 没有内置 eUICC，因此该卡不能管理或下载 eSIM 套餐。

## Wi-Fi 扫码分享

新增「分享 Wi-Fi」入口，概览可直接进入，也位于 Wi-Fi 分类下。选择 2.4 GHz、5 GHz 或访客网络后，以当前已保存的名称、密码、加密方式及隐藏标志生成连接二维码；不会读取尚未保存的表单草稿。关闭或状态不完整的热点只显示原因，不能生成误导性的连接码。亮屏页面每 30 秒静默检查，只在连接内容变化时更新二维码。

- 使用标准 `WIFI:` 内容，正确转义反斜线、分号、逗号、冒号和双引号，保留 UTF-8 SSID；混合 WPA2/WPA3 使用兼容的 WPA 标记，纯 WPA3 使用 SAE。
- 256 像素黑白二维码按整数像素绘制并居中，SSID 单独显示；锁屏、熄屏、离开页面时清除图像。不会在日志、偏好配置或截图样例中保存真实热点密码。
- 43 项 Rust 测试、7 项恢复守护测试及 Clippy 通过；使用独立 `rqrr` 解码器从完整 320×480 模拟截图读回二维码，中文 SSID、复杂密码和加密标记均与预期一致。新增 UI 回归覆盖网络选择和锁屏清除。
- ARM64/musl 静态编译通过：ELF 26,548,200 字节；`size -A` Total 26,506,625；gzip level 9 / mtime 0 为 16,050,313 字节。SHA-256：`b865996531cc2ed680dcf3408ab75c23325562ee8cfbdf9953e8cf8986bf814c`。
- 本机 B31 的两项 Wi-Fi 读取均成功，主热点为 WPA2/WPA3 混合模式。用户在 180 秒限时试用中确认「二维码能识别并连接」。试用正常结束，恢复守护确认原厂 UI 已运行、背光已恢复。此实测验证了用户所选热点；访客网络、隐藏网络与纯 WPA3 的其他手机组合仍以代码测试为限。

NFC 只读核对：原厂 `zwrt_nfc` 提供 Wi-Fi 相关方法，`zwrt_nfc_wifi_get` 返回开关已开启。此轮没有修改 NFC 配置，也没有新增未经验证的 NFC 写入接口；真实碰触连接与手机兼容性尚未验证。


## 代理与远程网络管理

新增「代理服务」「代理节点」两个原生入口，支持读取真实状态、确认启停/重启、停止时修改分流策略与流量范围、选择路由组与节点。计划执行前重新核对服务状态，后台再次核对组成员。Tailscale 设置补充「接收远端子网路由」，与 Web 使用相同的 `accept_routes` 字段。

45 项 Rust 测试与严格 Clippy 检查通过。后台及实机内核验证边界见 [网络服务管理](../docs/network-services.md)。

## 状态栏与直供电控制

锁屏与解锁后共用状态栏：四格蜂窝信号根据实测 RSRP 显示，无服务显示叉号，读数未知显示问号。充电时闪电与电量图标闪动；接入电源但未充电显示插头，直供电显示带箭头的插头。充满、拔电和状态失效后停止充电动画，熄屏不运行动画。锁屏电量卡片同时显示当前供电状态。

「设备 → 电池与电源 → 电池详情」提供「启用直供电／关闭直供电」，「充电策略」也提供同名开关。设备通过同一个控制项启用直供电并停止电池充电；关闭后由充电上限策略决定是否恢复充电。操作需要机身解锁与确认，提交前核对状态，提交后回读；只切换该控制项，不重写充电上限。拔掉外接电源后使用电池。

原生回归覆盖充电、充满、直供电、普通外接电源、反向供电、缺失与过期数据，以及开关确认、状态变化取消写入和操作后回读。渲染测试检查锁屏和解锁后的实际动画帧与静止直供电图标，截图仅用演示数据。本轮未执行实机直供电切换。

首页与锁屏标题现显示新鲜蜂窝读数中的运营商名称，保留网络制式、频段与速率；无服务或读数缺失时明确显示对应状态，不保留过期运营商。健康连接不再在顶部显示“实时”，断线和登录提示仍可显示。54 项屏幕回归及合成画面验证通过。

## 概览 Wi-Fi 连接卡片（2026-11-04）

概览首屏直接显示连接二维码，旁边显示热点名称、频段和默认遮盖的密码。眼睛按钮切换密码显示，15 秒后自动遮盖；长密码可换行完整查看。点二维码进入放大视图，返回保持在概览。

2.4 GHz 与 5 GHz 均开启，且已保存的名称、密码、加密方式及隐藏设置一致时，两个频段共用一个连接码，手机自行选择。设置不同则保留频段切换，单个频段关闭时使用另一有效热点；不会自动修改设备的双频设置。访客网络继续从 Wi-Fi 分类分享。

- 每 30 秒读取热点状态；断线、失效读数、锁屏、熄屏及离开概览均清除二维码和可见凭据。锁屏仍显示网络状态，不显示连接码。
- 原生屏幕 56 项测试通过，覆盖实际触摸、密码自动遮盖、锁屏清除、双频合并与切换。简体、繁体、英语、日语、韩语画面已核对。
- 148 像素首页二维码与 256 像素放大码均按整数像素绘制。独立 `jsQR` 解码器从明暗主题、多语言和最长字段的 320×480 合成截图中还原了预期连接信息。
- B31 只读核对确认本机两频段已开启且上述设置相同。本轮未向机身安装新版本，新卡片的手机扫码体验仍需升级后验收；[概览截图](docs/overview-wifi.png)仅使用合成热点数据。

代理服务页增加「重新加载配置」，只对已启动且已有配置的服务开放。提交前核对配置版本；新服务路径的启动、停止、重启与 reload 使用较长的请求超时，避免沿用普通读取的 30 秒超时。55 项原生回归通过，配置版本变化会取消旧操作。
