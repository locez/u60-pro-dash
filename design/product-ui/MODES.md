# 连接与性能交互设计

实现说明与真实接口见 [连接与性能模式](../../docs/operating-modes.md)。以下保留设计阶段的依据与验证范围。

2026-11-07。设计阶段只更新浏览器设计稿，操作使用共享的本地示例状态，不调用设备 API、不修改设备配置。性能档位的效果文案表达设计目标，尚未做实机功耗或吞吐验证。

## 功能分工

| 项目         | 设计行为                                                     | 与其他设置的关系                                                 |
| ------------ | ------------------------------------------------------------ | ---------------------------------------------------------------- |
| 飞行模式     | 关闭蜂窝无线电、数据、通话和短信；保留 Wi-Fi、USB 与本地管理 | 开启前提示远程连接中断；关闭直接恢复蜂窝，不自动重启设备         |
| 性能模式     | 均衡、性能、省电三档，选中即应用                             | 不切换网络制式、Wi-Fi 频段、供电方式或服务开关；始终保留温度保护 |
| 应用带宽策略 | 极速、AI 智能、游戏、视频、会议、直播                        | 独立于性能档位；极速表示应用竞争带宽，不表示 CPU 满速            |
| 高铁优化     | 显示自动状态：未触发、工作中、暂停、未知                     | 目前只找到状态来源，不提供手动开关                               |

“均衡 + 极速”和“性能 + 游戏优先”都是有效组合。飞行模式保留所选档位和带宽策略；界面表达蜂窝侧效果暂停，不能据此假定原厂调度进程已停止。网络自愈不能在用户主动关闭蜂窝后擅自重新开启无线电。

## 入口与状态展示

| 位置                             | 内容与操作                                                             |
| -------------------------------- | ---------------------------------------------------------------------- |
| Web 顶栏                         | 快捷控制：飞行模式、性能三档、高铁状态；分别链接到移动网络和电源与电池 |
| Web 概览                         | 蜂窝状态、当前性能档位、带宽分配；优先提示高铁优化与温度保护           |
| Web 移动网络 → 连接设置          | 飞行模式直接操作；网络优化区域包含带宽分配与高铁自动状态               |
| Web 系统设置 → 电源与电池        | 性能三档与电池、供电设置                                               |
| 屏幕顶部状态栏                   | 解锁后点击打开快捷控制；图标右对齐，隐藏项不占位                       |
| 屏幕状态首页                     | 运营商旁显示当前性能档位；点击打开快捷控制                             |
| 屏幕连接 → 移动网络              | 飞行模式、带宽分配、高铁自动状态                                       |
| 屏幕管理 → 电源与电池 → 性能模式 | 均衡、性能、省电三档与温度保护提示                                     |
| 锁屏                             | 展示模式与网络状态，无设置入口；沿用长按 1 秒和可选 PIN 解锁           |

快捷入口与正式分类分开。系统设置不再设“运行模式”分类；旧设计链接自动转到移动网络的连接设置。快捷面板的两个链接分别回到真实设置归属，屏幕返回路径也与“连接／管理”主分类一致。

产品内用“带宽分配”表达用途。选项说明只描述当前策略：极速为“不区分应用优先级，按需使用带宽”；游戏优先为“优先保障游戏流量”。不再在屏幕中解释“可与任一性能档位组合”，也不为已清晰显示的选项重复添加说明段落。分组依据与原厂技术细节保留在本文中。

飞机图标替换蜂窝信号与制式。默认均衡不额外占用状态栏图标；省电用叶片，性能用仪表，高铁工作中用列车。温度保护图标优先于性能图标，完整档位仍显示在锁屏或设置中。充电与直供电保留独立图标，避免用同一个闪电表示性能。

飞行模式下，首页与锁屏的蜂窝速率、信号数值显示 `—`，不会继续显示在线示例读数。Web 保留历史趋势，锁屏以暂停提示替代实时图表。Wi-Fi 连接码留在解锁首页；锁屏不显示密码或二维码。服务进程运行与远端连通性仍是不同状态，不能由模式切换推断服务已退出。

浅色、深色和强调色均沿用现有主题。320 × 480 首页无需滚动；完整设置与错误提示在详情容器内滚动。原生实现保持增量更新和熄屏暂停采样，不新增常驻动画或背景模糊。

## 操作反馈

- 开启飞行模式：确认中断影响 → 正在关闭 → 回读确认已关闭。取消保留原状态。
- 关闭飞行模式：正在恢复无线电与网络注册 → 回读确认结果。失败保留可确认的模式状态，给出重试和诊断方向，不把发送命令成功当作联网成功。
- 性能与带宽选项：直接应用并回读；失败保留旧值，显示错误，不追加保存按钮。
- 温度保护：保留用户选中的档位，同时说明实际处理能力正在受限。不能宣称一直满速或绕过温控。
- 状态未知：显示未知、禁用依赖当前值的修改；不把空字段当作已关闭或默认均衡。

预览顶部的“模式演示”可切换正常、高铁自动优化、温度保护、状态暂不可用、设置应用失败、蜂窝恢复失败。正常场景不会清空用户选择，便于评审跨页面状态一致性。900 毫秒的切换延时仅用于展示过程，不是实际设备的超时设定。

## 原型验证

TypeScript 和 Vite 构建通过；分类调整后补充检查新旧入口、快捷链接、屏幕返回路径及错误按对应设置展示。Chromium 检查覆盖 Web 与屏幕共享状态、性能与带宽独立选择、飞行确认与取消、恢复与失败、锁屏禁止修改、长按解锁、未知状态禁用、浅深主题及 390 像素 Web 宽度。首页滚动区域为 393 / 393 像素，导航之外没有被隐藏的首页内容。浏览器无运行错误，资源请求全部留在本机。

这些检查验证交互稿，不代表真实硬件恢复、温控或续航已经验证。公开截图使用发布预览和虚构网络信息。
